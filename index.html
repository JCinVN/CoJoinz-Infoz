Edit & Data

Quick text fixes

Once on, click any title or paragraph on the page to edit it directly, like typing in a text box. Click elsewhere when done. This only changes the current page in your browser — before you close or refresh, click "Download updated file" below to save.

Bulk edit with Excel

Click "Export to Excel" to download the current content (columns: ID, Level, Title, Content, Type) on its own sheet named "CoJoinz INFOZ".
Edit it in Excel: a row with Title filled in is a heading (Level is its depth — 1 for a top chapter, 2 for a sub-section, and so on); a row with Title blank and only Content filled in is a paragraph attached to the heading above it.
A row with Type = "table" is a game data table: its Content cell just names another sheet in this same file (e.g. "T_3.7") — open that sheet to edit the table's own real columns and rows directly. Don't rename that sheet unless you also update the matching Content cell to the new name.
Save the file, come back and click "Import from Excel" to pick it — the page updates immediately.

Save your changes

Whichever way you edited, click this button when you're done — it downloads a brand-new, fully working index.html with your changes baked in. Use it to replace the old file (and re-upload it to GitHub too, if this is hosted there).
